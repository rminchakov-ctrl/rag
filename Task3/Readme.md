# Создание векторного индекса базы знаний

## Подготовка среды и установка зависимостей
``` bash
python3 -m venv .venv

pip3 install -r requirements.txt
```

## Запуск скрипта
``` bash
python3 build_index.py
```

## Проверка индекса
``` bash
python3 test_index.py
```
